# ALI DRINKS 🥤

A modern animated product website created for a milkshake brand, focused on cinematic visuals, smooth scroll interactions, responsive design, and an engaging user experience.

## ✨ Project Overview

ALI DRINKS is a personal frontend/web design project created to explore creative web interactions, visual storytelling, and smooth scroll-based animations.

The website is designed to present a milkshake brand through a bold and memorable digital experience.

## 🚀 Features

* Cinematic scroll-based animations
* Smooth interactive transitions
* Responsive design
* Modern product-focused UI
* Engaging visual storytelling
* Mobile-friendly layout

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
* Responsive Web Design
* Scroll Animations
